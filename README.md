# 💳 Money Muling Detection

An AI-powered Anti-Money Laundering (AML) platform that detects money mule networks, suspicious transactions, and financial fraud using machine learning, graph analytics, and intelligent risk analysis.

---

## 🚀 Overview

Money Muling Detection is an intelligent fraud detection system designed to help financial institutions identify money mule accounts and suspicious transaction patterns. The platform leverages machine learning, graph-based analysis, and interactive visualizations to uncover hidden fraud networks and support Anti-Money Laundering (AML) investigations.

---

## ✨ Features

- 💰 Money Mule Account Detection
- 🤖 AI-Powered Fraud Risk Prediction
- 🕸️ Graph-Based Transaction Network Analysis
